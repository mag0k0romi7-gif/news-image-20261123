# The World in One Page — Monday, 23 November 2026

An entry for make.fun's [“Sum up 23 November's world news in one image”](https://make.fun/bounty/news-image-20261123) bounty.

A one-image summary of the world's news of Monday 23 November 2026, drawn as a
newspaper front page: the COP31 climate talks collapse with no deal — the first
failure since Copenhagen 2009; Xi, Trump and Putin hold their first trilateral
talks; the Democrats clinch a historic House majority; Ukraine says it sank a
Russian warship off Libya; Ebola deaths pass 5,700 in DR Congo — plus 32 more
date-checked stories from 9 regions, 37 in all.

Run: `python3 main.py` — it draws `entry.png` (1024x1024 PNG) into the output
directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` outside the grader) with Pillow.
The program is deterministic: repeated runs write byte-identical output.
